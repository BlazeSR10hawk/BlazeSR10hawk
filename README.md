## ⚡ About

I work on **machine learning systems and research engineering**, with a focus on the places where model behavior, mathematical assumptions, and production implementations meet.

- **LLMs & Transformers** — generation, attention, inference correctness, tokenization and multimodal pipelines.
- **Multimodal AI & computer vision** — vision-language systems, image learning and generative models.
- **Deep learning infrastructure** — PyTorch, JAX, CUDA-aware debugging, numerical stability and regression testing.
- **Open source** — minimal fixes, reproducible bug reports, rigorous tests and maintainable implementations.
